GOVT. BOYS MS G-JAMGAON — WEBSITE STARTER

Files:
- index.html: website content
- style.css: responsive design
- script.js: Hindi/English toggle and local demo notice panel

IMPORTANT:
This is a static website starter. The Admin area is only a browser-local demonstration:
- It has no secure login.
- Demo notices are stored only in the current browser/device.
- It does not publish notices to other visitors.
Do not enter student personal data, marks, phone numbers, or confidential records.

For a real Advanced Admin Panel (secure teacher/headmaster login, shared notices, PDFs,
gallery uploads and result publishing), connect a backend such as Firebase or Supabase
before using it with real student information.

FREE HOSTING:
GitHub Pages can host this static website free in a public repository.
1. Create/sign in to GitHub.
2. Create a public repository named govt-boys-ms-g-jamgaon.
3. Upload index.html, style.css, script.js.
4. Open repository Settings > Pages.
5. Under Build and deployment, select Deploy from a branch; choose main and /(root), then Save.
6. After publishing, use the Visit site link shown in Pages settings.

See official guide:
https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
